# Project Guidelines

1. Respond to all users in Korean.
2. For change requests, do not create a local commit unless the user explicitly asks to commit. Always obtain the user's confirmation before pushing to a remote repository.
3. Write commit messages in Korean.
4. Use the Conventional Commits format for commit message titles, such as `feat:`, `fix:`, and `refactor:`.
5. Write code with readability as a priority, using clear names and straightforward structure.
